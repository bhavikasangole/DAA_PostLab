Course: Design & Analysis of Algorithms (N-PCCCD501P) | Session 2026–27

Practical List

Practical Aim / Problem Statement Algorithm / Concept CO Mapped
Pre-Lab Analyse the time and space complexity of an algorithm that generates all prime numbers up to a given value n, and perform empirical comparisons for inputs such as 100, 1000, 10000, and 100000. Complexity Analysis CO1
Practical 1 You are a DevOps engineer at a data center in Pune... To help the DevOps team trace the exact sequence of events leading to failure, sort log entries chronologically using timestamps. Quick Sort CO2
Practical 2 You are the chief archivist at Nalanda Mahavihara... The priest must receive the oldest preserved copy (first occurrence of Archive ID). Apply Binary Search to locate it efficiently. Binary Search CO2
Practical 3 You are an engineer aboard an ISRO spacecraft en route to Mars. The computer performs $4\times4$ matrix multiplications. Split into $2\times2$ quadrants using Strassen's algorithm recursively. Strassen's Algorithm CO3
Practical 4 A government is planning a nationwide high-speed fiber internet network. Connect all cities while minimizing total construction cost using Kruskal's Minimum Spanning Tree Algorithm. Kruskal's MST CO3
Practical 5 Develop a real-time emergency ambulance routing system for Mumbai. Compute the shortest travel time from hospital to all city locations using Dijkstra's Algorithm. Dijkstra's Algorithm CO2, CO3
Practical 6 A logistics company deploys autonomous drones to deliver medical supplies across Indian cities. Visit every city once and return to HQ using Dynamic Programming for TSP. Travelling Salesman Problem CO2, CO3
Practical 7 You are a bioinformatics scientist comparing DNA samples from two species. Determine the length of the Longest Common Subsequence (LCS) to identify shared traits. Longest Common Subsequence CO2, CO3
Practical 8 As a financial analyst at RBI monitoring currency exchange rates, detect negative weight cycles corresponding to arbitrage opportunities using the Bellman-Ford Algorithm. Bellman-Ford Algorithm CO2, CO3
Practical 9 Place $N$ high-frequency antennas on an $N\times N$ grid without electromagnetic interference in the same row, column, or diagonal line of sight using N-Queens Problem formulation. N-Queens Problem CO2, CO3
Practical 10 Trace social media post reach by prioritizing a single chain of interactions to its conclusion before backtracking using Depth-First Search (DFS). Depth-First Search CO2, CO3
Post-Lab Open-ended practical defined by students. Student-defined CO1-CO4
