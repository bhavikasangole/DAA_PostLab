# 📘 Design & Analysis of Algorithms – Practical

This repository contains the practical implementations for the
Design & Analysis of Algorithms (DAA) course.

## 🧪 Practical Index

| Practical | Problem Statement | Algorithm / Concept | CO |
|---|---|---|---|
| Pre-Lab | Prime number generation and complexity analysis | Complexity Analysis | CO1 |
| Practical 1 | Sort massive server logs chronologically | Quick Sort | CO2 |
| Practical 2 | Find first occurrence of manuscript Archive ID | Binary Search | CO2 |
| Practical 3 | Fast 4×4 matrix multiplication | Strassen's Algorithm | CO3 |
| Practical 4 | Minimum-cost fiber network connecting cities | Kruskal's MST | CO3 |
| Practical 5 | Emergency ambulance shortest-path routing | Dijkstra's Algorithm | CO2, CO3 |
| Practical 6 | Minimum-cost drone delivery route | TSP + Dynamic Programming | CO2, CO3 |
| Practical 7 | Compare DNA sequences | Longest Common Subsequence | CO2, CO3 |
| Practical 8 | Detect currency exchange arbitrage | Bellman-Ford Algorithm | CO2, CO3 |
| Practical 9 | Antenna placement without interference | N-Queens Problem | CO2, CO3 |
| Practical 10 | Determine social media post reach | Depth-First Search | CO2, CO3 |
| Post-Lab | Open-ended practical | Student Defined | CO1, CO2, CO3, CO4 |
